# Student Grade Calculator

## 📌 Overview

Student Grade Calculator is a Java console application that allows users to enter marks for five subjects, calculate the total marks, determine the average percentage, and assign a final grade based on the student's performance.

The application includes robust input validation to ensure that all entered marks are valid and within the allowed range.

---

## 🚀 Features

* Enter marks for **5 subjects**
* Calculate the **total marks**
* Calculate the **average percentage**
* Determine the **student's grade**
* Validate marks to ensure they are between **0 and 100**
* Handle invalid character or text inputs gracefully
* Display results in a clean and formatted output

## 📊 Grade Calculation

| Percentage | Grade |
| ---------- | ----- |
| 90 - 100   | A     |
| 80 - 89    | B     |
| 70 - 79    | C     |
| 60 - 69    | D     |
| 50 - 59    | E     |
| Below 50   | Fail  |

---

## ⚙️ How It Works

1. The user enters marks for five subjects.
2. The program validates each mark:

   * Marks must be between **0 and 100**.
   * Non-numeric inputs are rejected.
3. The program calculates:

   * Total Marks
   * Average Percentage
   * Final Grade
4. Results are displayed in a formatted report.

## 🔒 Input Validation

The application prevents:

* Marks below **0**
* Marks above **100**
* Character or text inputs instead of numbers

This ensures accurate calculations and improves the reliability of the program.
